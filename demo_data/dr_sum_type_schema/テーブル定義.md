# Dr.Sum 物理カラム ダミースキーマ テーブル定義書

## 概要

Dr.Sumがサポートするデータ型(以下8種類)を、全体で偏りなくカバーするために作成したダミースキーマです。

| データ型 | 意味・用途の目安 |
|---|---|
| REAL | 単精度浮動小数点数。測定値やスコアなど小数を含む実数 |
| NUMERIC | 固定小数点数(精度・スケール指定)。金額など桁数を厳密に管理したい数値 |
| VARCHAR | 可変長文字列。コード・番号・名称・住所など |
| INTERVAL | 時間の間隔(期間)。「〜所要時間」「〜期間」など、2点間の長さを表す値 |
| DATE | 日付のみ(年月日) |
| TIME | 時刻のみ(時分秒) |
| TIMESTAMP | 日付+時刻。「〜日時」 |
| OBJECT | バイナリラージオブジェクト。画像・PDF・スキャンファイルなど添付ファイル類 |

テーブルは5個、業務テーマを分散させて作成しました(同じ型のカラムを1テーブルに集中させず、複数テーブルに分散配置することで型の偏りを避けています)。テーブル名・カラム名は既存デモデータ(`T_売上明細`、`T_顧客M`、`T_商品M`、`T_在庫`、`V_売上_月次集計`)と重複しない名前にしています。

**注意**: 以下のデータ型名・桁数はDr.Sumの一般的な仕様を想定して記載していますが、実際のDr.SumバージョンでのDDL方言(型名の正式表記・最大桁数・OBJECT型の制約等)は未確認です。実際にCREATE TABLEを実行する前に、Dr.Sum公式のSQLリファレンスで型名・構文を確認してください。

## 1. T_配送案件 (配送・物流管理)

| カラム名 | データの型 | 精度/スケール・桁数 | NULL | 説明 |
|---|---|---|---|---|
| 配送案件コード | VARCHAR | (20) | NOT NULL | 配送案件を一意に識別するコード |
| 受付日時 | TIMESTAMP | - | NOT NULL | 配送依頼を受け付けた日時 |
| 出荷予定日 | DATE | - | NULL可 | 出荷予定の日付(年月日のみ) |
| 配送所要時間 | INTERVAL | - | NULL可 | 出荷から配達完了までの所要時間 |
| 運賃 | NUMERIC | (10,2) | NULL可 | 配送料金(円、小数点2桁まで) |

## 補足: 既存デモデータとの名前重複チェック

既存デモデータ(`T_売上明細`、`T_顧客M`、`T_商品M`、`T_在庫`、`V_売上_月次集計`)とテーブル名・カラム名の重複はありません。業務テーマも既存デモデータ(売上・顧客・商品・在庫)とは異なる領域(配送、設備保守、契約、コールセンター、勤怠)を選んでいるため、意味的な重複もありません。
